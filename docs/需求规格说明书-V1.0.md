# 选题：基于Spring Boot+Vue的冷库设备综合运维管理系统的设计与实现

> 文档版本：V1.0（定稿审查稿）  
> 说明：本系统为**纯传统业务系统**，不包含大模型、Spring AI、RAG、智能问答等 AI 能力。  
> 可选增强（非必须）：Redis 缓存、WebSocket 实时消息、文件上传、Excel 导入导出。

---

## 技术栈

| 端 | 技术 |
|---|---|
| 前端 | Vue 2 + ElementUI + Axios + ECharts |
| 后端 | Spring Boot + MyBatis-Plus + MySQL |
| 可选 | Redis、WebSocket、本地/对象存储文件上传、Apache POI（Excel） |

---

## 角色定义

| 角色 | 代码 | 说明 |
|---|---|---|
| 管理员 | ADMIN | 全平台配置、派单管控、用户权限、全局统计 |
| 运维人员 | OPS | 处理指派工单/维保任务、故障与案例、备件出库相关操作 |
| 甲方用户 | CLIENT | 可查看全部设备并报修（含公共设备）；查看本人工单进度、确认验收、评价 |

**数据权限原则**

- 甲方：可查看系统内**全部设备**（含各冷藏间设备与公共设备），并可对**公共设备及普通设备发起报修**；工单侧仅查看/操作**本人提交**的工单；无故障内部模块等运维专属入口。  
- **冷藏间绑定保留**：管理员仍可为甲方勾选绑定多个冷藏间，仅用于个人中心等归属展示，**不再限制**设备可见范围与报修范围。
- 运维：按“负责区域/指派工单”处理业务；列表可见范围以实现方案为准（建议：全库可见或按负责冷库可见，处理仅限指派给自己的单据）。
- 管理员：全部数据。

# 一、前端主要功能（Vue 2 + ElementUI + ECharts）

## 1. 登录认证与权限管理

支持管理员、运维人员、甲方用户三类角色账号密码登录（JWT Token 认证）。  
登录后通过路由守卫按角色动态渲染侧边栏菜单，隐藏无权限入口；无权限页面自动拦截并跳转首页。  
支持按钮级权限控制（如派单、删除、导入导出等按角色显示/禁用）。  
支持退出登录、清除本地登录状态。  
全角色提供个人中心：查看/修改姓名、联系方式、修改登录密码。  
管理员支持用户启用/禁用（用户状态管理）。  
系统记录关键操作日志（登录、派单、删改设备、出入库等），管理员可查询。

## 2. 冷库管理

冷库为整座库区（如广西龙门港冷库）。  
支持冷库列表与基础信息维护（增删改查）。  
字段包含：冷库名称、地址、联系人、联系电话、投用时间、冷库状态（启用/停用）、备注；列表可展示下属冷藏间数、设备数（仅作规模提示）。

### 2.1 库区详情（定位：单库「办事台」，不是报表页）

进入某座冷库后的详情页，目标是**现场处置入口**，回答：「这座库现在有什么事要办？」

**应包含：**
- 基础档案（联系人、地址、启用状态）
- 下属冷藏间清单（可跳转维护）
- **待办清单**：本库未完成工单、本库紧急/临近维保、本库异常设备（故障/维修中）
- **操作入口**：去派单/处理工单、去看设备、去维保提醒

**不应作为重点（避免与数据统计重复）：**
- 完成率、近 N 月趋势、类型分布饼图、跨库排名等分析指标

演示可预置 1～2 座冷库。

## 3. 冷藏间管理

冷藏间隶属于冷库；组态现场「冷库1～11」在本系统统一称为「冷藏间」。  
管理员：冷藏间新增、编辑、删除、多条件查询、按冷库筛选、分页。  
字段包含：所属冷库、名称、编码、状态、温度范围（下限/上限）、容积、备注等。  
支持在用户管理中为甲方勾选绑定多个冷藏间（多对多）。  
甲方：冷藏间列表可查看（与设备全可见策略一致）；**绑定关系保留**，用于个人中心展示所属冷藏间，不作为设备/报修权限边界。

## 4. 设备台账管理

设备必须归属冷藏间；机房公共主机等标记为公共设备。  
设备类型贴近现场：约克主机、比泽尔主机、复叠活塞机、冷藏间蒸发器/风机、融霜相关设备、排水电热、传感器/保护类等。  
设备字段包含：设备编号、设备名称、设备类型、品牌、型号、所属冷藏间、是否公共设备、投用日期、设备状态、负责人、额定参数、维保周期、当前累计故障次数、备注。  
管理员/运维：多条件查询、分页、详情、新增、编辑、删除。  
支持 Excel 导入、Excel 导出（可选优先实现导出，导入次之）。  
甲方：可查看**全部设备**（含公共设备）；不可编辑、删除设备；**可以对公共设备发起报修**，也可对普通设备报修。面向甲方的详情可屏蔽部分运维内部字段（如内部备注）。

## 5. 设备生命周期管理

设备状态流转：

> 正常 → 故障 → 维修中 → 待验收 → 恢复运行（正常）→ 报废

支持记录设备历史状态变化（时间、原状态、新状态、操作人、原因/备注）。  
设备详情中可查看状态变更时间线。  
工单报修、接单处理、验收完成等业务节点应联动更新设备状态（规则在实现阶段按状态机落地）。

## 6. 运维工单全流程管理（系统核心）

工单状态：

> 待受理 → 已派单 → 处理中 → 待验收 → 已完成 → 已评价 → 已归档

**甲方**

- 选择设备提交报修（可选任意设备，**含公共设备**）  
- 填写故障描述，上传现场图片  
- 查看本人工单列表、处理进度、处理人员  
- 对「待验收」工单进行确认完工  
- 对已完成工单进行服务评价  

**运维**

- 查看待处理/指派给自己的工单  
- 接单、开始处理  
- 填写处理过程、故障原因、处理方案、维修耗时  
- 填写使用备件（关联库存扣减）  
- 上传维修图片  
- 提交完工（进入待验收）  

**管理员**

- 查看全平台工单  
- 派单、转派、撤回、关闭、重开  
- 按状态、时间、设备/冷藏间等多条件筛选  

工单详情完整展示：工单编号、冷库/冷藏间/设备、故障描述、图片、提交人/时间、指派运维、处理过程、备件、状态、验收与评价信息。

## 7. 故障记录管理

运维/管理员：新增、编辑故障记录；可关联设备与工单。  
字段包含：故障编号、设备、冷藏间、故障类型、故障等级、故障现象、故障原因、处理方案、开始/结束时间、处理耗时、维修人员、关联工单、使用备件、故障图片、备注。  
故障类型字典（现场化）：高压异常、低压异常、油压异常、油温异常、电机过载、温度传感器故障、压力传感器故障、融霜异常、排水异常、风机故障、电热异常、通讯异常、控制器故障等。  
管理员：支持按设备、故障类型、时间范围查询与删除。  
甲方：无故障记录模块入口与访问权限。

## 8. 故障案例库（非 AI）

普通运维经验数据库，支持历史案例查询，不涉及大模型。  
案例字段：故障现象、故障类型、故障原因、排查方法、处理方案、适用设备类型、注意事项、相关附件。  
运维/管理员可按「设备类型 + 故障类型 + 关键词」检索案例。  
管理员（及授权运维）可维护案例增删改。

## 9. 维保计划管理

将原「维保提醒」扩展为完整计划模块。  
管理员制定：月度 / 季度 / 半年度 / 年度维保计划。  
可按设备类型配置维保检查项目（如压缩机：油位、油温、高低压、电流、运行声音；蒸发器：风机、结霜、排水、电热等）。  
系统计算计划/任务状态：即将到期 / 已到期 / 已完成（及逾期）。

## 10. 维保任务（维保工单）

维保与故障维修工单分开。  
根据维保计划生成维保任务（针对具体设备）。  
运维完成维保后填写：检查项目、检查结果、是否异常、处理措施、使用备件、维保人员、维保时间。  
管理员可查看任务执行情况与完成率。

## 11. 备件库存管理

备件档案：备件编号、名称、类型、规格、品牌、单位、当前库存、安全库存、供应商、单价、备注。  
库存操作：入库、出库、盘点、库存调整；保留出入库流水。  
维修/维保工单使用备件时自动扣减库存。  
当当前库存 < 安全库存时产生库存预警（进入消息中心）。

## 12. 供应商管理

供应商信息：名称、联系人、电话、地址、供应范围、合作状态、备注。  
实现供应商与备件一对多关联。  
管理员维护供应商档案；备件可选择所属供应商。

## 13. 设备维修档案

在设备详情中展示完整维修/运维档案：  
累计故障次数、维修次数、维保次数、最近一次故障时间、平均维修时长、累计使用备件数等。  
下列表展示该设备关联的故障工单、故障记录、维保任务与备件消耗历史。

## 14. 设备健康分析（规则计算，非 AI）

基于历史数据统计：故障次数、维修次数、维保次数、平均故障间隔、平均维修时间、最近故障时间。  
按业务规则输出健康等级，例如：  
- 一年故障 ≤ 2 次：正常  
- 一年故障 3～5 次：关注  
- 一年故障 > 5 次：预警  

列表/详情展示健康等级，支持筛选关注与预警设备。

## 15. 数据统计中心（ECharts）

**定位：全系统「分析台」，不是办事入口。**  
回答：「这段时间整体运行怎么样？问题集中在哪？」  
与第 2 章库区详情分工：库区详情只看**单库当下待办**；本模块看**全库区、可按时间汇总**的图表与指标。

管理员（及授权角色）进入数据中心，支持按时间筛选与刷新。

**工单分析**：月度工单量、完成/未完成量、完成率、平均响应时间、平均维修时间。  
**故障分析**：故障类型分布、故障趋势、故障最多设备/冷藏间、重复故障统计。  
**维保分析**：本月维保、已完成、逾期、维保完成率。  
**库存分析**：当前库存概况、低库存备件、本月出库、使用最多备件。

运维个人看板：待处理工单数、本月完成数、临近维保任务清单等（个人维度，仍属分析/摘要，不替代库区详情里的「去办事」入口）。

## 16. 消息提醒中心

统一消息列表，支持已读/未读。  
消息类型包括：新报修提醒、派单提醒、工单超时提醒、工单完成提醒、维保到期/逾期提醒、库存不足提醒等。  
有余力可采用 WebSocket 实时推送；初版可用登录后拉取 + 定时刷新。

## 17. 用户与数据权限

管理员：用户增删改、角色分配、启用/禁用、甲方冷藏间绑定、运维负责区域配置（可选）。  
权限与菜单/按钮联动。  
操作日志查询（管理员）。

# 二、后端主要功能（Spring Boot + MyBatis-Plus + MySQL）

## 1. 身份认证与权限隔离

基于拦截器（或等价机制）校验 Token，区分三角色接口访问范围。  
密码 BCrypt 加密存储；登录成功返回 Token。  
按钮/接口级鉴权：未登录、越权、禁用用户均拦截。  
业务数据隔离：甲方可查询全部设备并报修（含公共设备），但工单仅限本人提交的单据；运维处理类接口仅允许操作指派给本人的工单/任务；管理员全量。  
提供操作日志写入与查询接口。

## 2. 冷库 / 冷藏间接口

冷库：增删改查、详情、下属统计（冷藏间数、设备数）。  
冷藏间：增删改查、按冷库筛选分页；字段含状态、温度范围、容积等。  
甲方绑定关系：用户↔冷藏间多对多的保存与查询。

## 3. 设备台账与生命周期接口

设备 RESTful 增删改查与多条件分页；字段覆盖品牌、型号、状态、负责人、额定参数、维保周期、累计故障次数等。  
面向甲方的设备接口屏蔽运维内部字段（如内部备注等）。  
Excel 导出接口；Excel 导入接口（可选）。  
设备状态变更接口与状态历史查询接口；关键业务节点自动写入状态历史。

## 4. 运维工单全流程接口

提交报修（生成唯一工单号，初始「待受理」；支持图片附件；允许选择公共设备）。  
派单/转派/撤回/关闭/重开（管理员）。  
运维接单、开始处理、提交处理过程（原因、方案、耗时、备件、图片）、提交完工（待验收）。  
甲方确认验收、服务评价、归档相关接口。  
按角色返回列表；支持状态、时间、设备/冷藏间筛选分页。  
工单使用备件时调用库存出库逻辑。

## 5. 故障记录接口

故障记录增删改查；关联设备与工单。  
故障类型、故障等级字典接口。  
仅运维与管理员可访问；甲方拒绝。  
组合条件分页查询。

## 6. 故障案例库接口

案例增删改查与附件信息。  
按设备类型、故障类型、关键词检索分页。  
权限：运维/管理员可查；维护权限可配置为管理员为主。

## 7. 维保计划与维保任务接口

维保计划 CRUD；维保项目模板（按设备类型）配置接口。  
按计划生成维保任务；任务状态更新与完成填报接口。  
到期/逾期计算与列表查询接口。

## 8. 备件与库存接口

备件档案 CRUD；入库、出库、盘点、调整及流水查询。  
安全库存预警查询。  
工单/维保领用备件出库接口（事务保证库存一致）。

## 9. 供应商接口

供应商 CRUD；供应商关联备件列表查询。

## 10. 设备档案 / 健康分析接口

设备维修档案汇总接口（次数、时长、最近故障、备件消耗等）。  
设备健康等级计算与列表/详情接口（规则引擎式统计，非 AI）。

## 11. 统计分析接口

全局统计（管理员）：工单、故障、维保、库存等多维 JSON，供 ECharts 使用。  
个人统计（运维）：待办、月完成、维保清单等。

## 12. 消息中心接口

消息生成（业务事件触发）、消息分页列表、标记已读/全部已读。  
可选 WebSocket 推送通道。

## 13. 用户与权限接口

用户增删改、角色分配、启用禁用、用户名唯一性校验。  
甲方冷藏间绑定；运维负责区域配置（若启用）。  
角色/权限字典；个人信息查询与改密。

# 六、实施约定（供你审查确认）
